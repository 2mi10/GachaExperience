# Gacha Experience

Unityで制作したガチャ演出のミニゲームです。

## Demo

https://2mi10.github.io/GachaExperience/

ブラウザ上で実際に動かすことができます。

## 概要

UnityのUI機能を使って、ガチャを引いたときの演出を制作しました。

ガチャのデータはJSONファイルから読み込み、
SR・SSR・URの3段階から抽選します。

抽選結果によって画面の表示やアニメーションを変えることで、
レアリティによる演出の違いを表現しています。

## 使用したもの

- Unity 6.4
- C#
- uGUI
- DOTween
- UniTask
- JSON
- GitHub Pages

## 主な機能

- SR・SSR・URの抽選
- レアリティごとの排出率表示
- レアリティに応じた演出
- JSONからのガチャデータ読み込み
- ガチャ演出中のボタン連打防止
- Webブラウザでの公開

## ガチャの仕組み

ガチャのデータをJSONファイルから読み込み、
それぞれに設定した重みを使って抽選しています。

現在はUnityのResourcesフォルダに置いたJSONファイルを使用しています。

例として、SR・SSR・URにそれぞれ異なる重みを設定することで、
レアリティごとの排出率を変えています。

## 演出について

ガチャの結果に合わせて、レアリティごとに演出を変えています。

SRでは小さな動き、
SSRではより大きな動き、
URではさらに大きな動きと色の変化を加えています。

アニメーションにはDOTweenを使用しています。

## 非同期処理について

JSONの読み込みにはUniTaskを使用しています。

今回はローカルのJSONファイルを使用していますが、
今後はPHPやNode.jsなどを使ってサーバーからデータを取得する形にも
発展させたいと考えています。

## 工夫した点

今回の制作では、ガチャの結果を表示するだけではなく、
結果によって演出が変わるようにしました。

また、ガチャを引いている途中にボタンを何度も押せないようにして、
演出が重なってしまわないようにしています。
